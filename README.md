# Site Mayná

Site institucional estático da Mayná, pronto para execução local.

## Abrir no Windows

Clique duas vezes em `iniciar-site.cmd`.

Também é possível abrir `index.html` diretamente em qualquer navegador moderno.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: identidade visual principal.
- `carousel.css`: carrossel e tratamento das fotografias.
- `script.js`: menu, animações e carrossel.
- `assets/`: retrato e imagens de projetos.

O site não precisa de Node.js, servidor ou instalação de dependências para funcionar.
